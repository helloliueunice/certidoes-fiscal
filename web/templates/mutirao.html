Planejar a emissão do mês

Envie as planilhas de controle (CSV) das conferências anteriores. O sistema mostra, para cada contratada, o que ainda está válido na data de corte e o que precisa ser emitido — para você resolver o mínimo de captchas, numa só sessão.

Estratégia para resolver menos captchas
  1. Peça à contratada. A contratada deve manter a regularidade durante todo o contrato (Lei nº 14.133/2021, art. 92, XVI) e, quando o contrato prever, enviar as certidões com a nota fiscal. Use o texto de solicitação de cada contratada.
  2. Use o SICAF. Uma consulta feita por você no {% if URL_SICAF %}SICAF (Compras.gov.br){% else %}SICAF (Compras.gov.br){% endif %}, na data do atesto, cobre federal, FGTS e trabalhista nos itens marcados "Automática". A declaração enviada pela contratada não serve ("simples consulta"); itens "Manual" foram inseridos pelo fornecedor e precisam ser conferidos no emissor.
  3. Emita só o que vence até a data de corte. O que ainda está válido fica para depois.
  4. Faça tudo numa sessão: CNPJ copiado, portais abertos em sequência, marque cada item como feito.
O sistema não contorna captcha: nos portais com captcha, é você quem resolve.
